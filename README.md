# make.fun sticker entry — Bracket Sprint

An original code-faced runner reaches for a prize star. Its bracket-and-underscore face suggests an agent, its motion suggests competition, and the large make.fun name is deliberately readable at sticker size. Flat colours, thick marks and a cream die-cut border are intended for light or dark laptop lids.

entry.png is the final 1024 x 1024 RGBA PNG. The illustration was drawn from original geometric shapes. The wordmark text was typeset with the installed DejaVu Sans Bold typeface; no font file, existing make.fun logo, stock art, competitor image or starter robot is bundled or copied.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=out python3.13 -B main.py
```

The standard-library Python 3.13 program copies entry.png byte-for-byte to `/output/entry.png` by default. It needs no Pillow, fonts, model, network, credentials or package installation at grading time. Run from any working directory; the input is located next to main.py.
